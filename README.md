## 你好，我是 yenaipaim

我是一名关注**桌面开发、开发者体验与实用自动化**的开发者。

相比追求功能堆叠，我更在意一个工具能否稳定地解决真实问题：少一点重复操作，多一点清晰反馈；少一点黑盒行为，多一点用户掌控。我的项目大多从日常摩擦出发，例如校园网自动认证、Python 初学者调试，以及编辑器内的学习反馈闭环。

我倾向于让软件遵循三个原则：

- **本地优先**：能在本机完成的数据和计算，尽量不依赖云端。
- **结果可靠**：自动化需要有状态检查、失败恢复和明确的退出条件。
- **保持透明**：工具应该解释自己做了什么，而不是替用户做不可见的决定。

在代码之外，我也喜欢看关系细腻、情绪克制、彼此照亮的故事，尤其偏爱女孩们并肩成长的作品。

## 代表项目

### School_Net_Auto_Auth

面向 Windows 10/11 的校园网托盘工具。应用会检测网络状态，通过 Playwright 启动独立的 Microsoft Edge 配置，并按用户录制过的步骤完成校园网认证；同时提供课程表导入、导出和桌面端管理功能。

`C#` `.NET 10` `WinUI 3` `Playwright` `Windows Credential Manager`

[查看项目](https://github.com/yenaipaim/School_Net_Auto_Auth)

### CODIA

一个面向 Python 初学者的 VS Code 调试学习助手。它从实际运行产生的 traceback 出发，通过“诊断、引导、验证、通关”的流程帮助学习者理解错误，而不是直接替用户修改代码。

`TypeScript` `VS Code Extension API` `Python` `OpenAI-compatible API`

[查看项目](https://github.com/yenaipaim/Code-Observation-Diagnosis-Intelligence-Assistant)
