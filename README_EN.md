## Hi, I'm yenaipaim

I'm a developer focused on **desktop development, developer experience, and practical automation**.

Rather than piling on features, I care about whether a tool can solve a real problem reliably: a little less repetitive work, a little clearer feedback; a little less black-box behavior, a little more user control. Most of my projects start from everyday friction — campus network auto-authentication, debugging for Python beginners, and a closed feedback loop for learning inside the editor.

I try to have my software follow three principles:

- **Local-first**: data and computation that can be done on the machine should not depend on the cloud.
- **Reliable outcomes**: automation needs state checks, failure recovery, and explicit exit conditions.
- **Stay transparent**: a tool should explain what it did, not make invisible decisions on the user's behalf.

Beyond code, I enjoy stories with delicate relationships, restrained emotions, and people who light each other's way — especially works about girls growing up side by side.

## Featured Projects

### School_Net_Auto_Auth

A campus network tray tool for Windows 10/11. The app detects network status, launches an isolated Microsoft Edge profile via Playwright, and completes campus network authentication following the steps recorded by the user; it also provides schedule import, export, and desktop management features.

`C#` `.NET 10` `WinUI 3` `Playwright` `Windows Credential Manager`

[View project](https://github.com/yenaipaim/School_Net_Auto_Auth)

### CODIA

A VS Code debugging learning assistant for Python beginners. Starting from tracebacks produced by actual runs, it helps learners understand errors through a "diagnose, guide, verify, clear" flow instead of just fixing the code for them.

`TypeScript` `VS Code Extension API` `Python` `OpenAI-compatible API`

[View project](https://github.com/yenaipaim/Code-Observation-Diagnosis-Intelligence-Assistant)
